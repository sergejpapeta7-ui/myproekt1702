HTML

HTML (HyperText Markup Language) — это язык гипертекстовой разметки, который служит фундаментом для создания веб-страниц. Он задаёт их структуру, определяя, где будут заголовки, абзацы, изображения, ссылки и другие элементы. Без HTML браузер не смог бы отобразить содержимое сайта.

История создания

HTML разработал британский учёный Тим Бернерс-Ли примерно в 1986–1991 годах в Европейском центре ядерных исследований (CERN) в Женеве. Изначально язык создавался как средство для обмена научной и технической документацией, удобное для людей, не являющихся специалистами в вёрстке. Первая версия включала всего 18 тегов и была упрощённой версией более сложного языка SGML.

Ключевые особенности

Не является языком программирования. HTML только структурирует контент и определяет его смысл, но не содержит логических операторов, циклов или переменных. Всё, что связано с интерактивностью и динамикой (анимация, валидация форм, сложные вычисления), требует интеграции с другими технологиями, например, JavaScript.

Основа для других технологий. HTML задаёт структуру страницы, CSS отвечает за её визуальное оформление (цвета, шрифты, расположение), а JavaScript добавляет интерактивность.

Семантическая разметка. Современные версии HTML (начиная с HTML5) включают теги, которые чётко описывают назначение контента: <header>, <main>, <article>, <footer>, <nav>. Это улучшает доступность для людей с ограниченными возможностями и помогает поисковым системам лучше понимать страницу.

Как устроен HTML

Теги — это основные строительные блоки HTML. Они выглядят как <имя> и указывают браузеру, как отображать содержимое. Большинство тегов парные (открывающий и закрывающий), но есть и одиночные (самозакрывающиеся), например, <br> или <img>.

Основные теги HTML

Ниже собраны теги, с которых начинается любая вёрстка: от структуры документа до таблиц, форм и мультимедиа.

Тег Назначение
<!DOCTYPE html>Указывает браузеру, что документ написан на HTML5
<html>Корневой элемент страницы, внутри него лежит весь документ
<head>Служебный блок: заголовок вкладки, кодировка, подключение стилей и шрифтов
<body>Видимая часть страницы — всё, что показывает браузер
<title>Название страницы на вкладке браузера
<meta>Служебная информация: кодировка, адаптация под мобильные, описание
<link>Подключение внешних файлов: CSS, иконка, шрифты
<script>Подключение или встраивание JavaScript-кода
<h1>…<h6>Заголовки шести уровней: h1 — главный, h6 — самый мелкий
<p>Абзац текста
<br>Перенос строки (одиночный тег)
<hr>Горизонтальная линия-разделитель
<strong>Важный текст — браузер делает его жирным
<em>Акцент на слове — курсив
<a>Ссылка на другую страницу, файл или якорь
<img>Картинка (одиночный тег, обязателен атрибут src)
<ul> / <ol>Маркированный / нумерованный список
<li>Элемент списка внутри ul или ol
<div>Универсальный блок-контейнер без смысла
<span>Универсальный строчный контейнер для части текста
<header>Шапка страницы или блока
<nav>Блок навигации — меню, ссылки
<main>Основное содержимое страницы
<article>Отдельная статья или запись
<section>Смысловой раздел внутри статьи
<footer>Подвал страницы: контакты, копирайт
<button>Кнопка, на которую можно нажать
<form>Форма для ввода данных
<input>Поле ввода: текст, пароль, галочка, кнопка
<table>Таблица
<tr> / <td> / <th>Строка / ячейка / ячейка-заголовок таблицы
<video> / <audio>Видео и аудио на странице
<iframe>Встроенный фрейм — например, карта или видео с YouTube
